# PISCINE//RUN

Офлайн-тренажёр коротких миссий для подготовки к отбору и фундаментальной базы программиста: Shell, Git, Python, C, алгоритмы и Unix.

## Запуск

Открой `index.html` двойным кликом — интернет, сборка и зависимости не нужны.

Для локального HTTP-превью:

```bash
python3 -m http.server 3000 --bind 0.0.0.0
```

Затем открой `http://localhost:3000`.

## Публикация на GitHub Pages

**Игра:** https://dipdizain-hub.github.io/game_1/

Код находится в ветке `arena/0cca4a20-game-1`; Pages включён в режиме GitHub Actions. Workflow `.github/workflows/pages.yml` публикует актуальный `index.html` при каждом его обновлении.

Для публикации используется окружение `piscine-run`: стандартное окружение `github-pages` разрешает деплой только из `main`, а вся работа этого проекта остаётся в рабочей ветке Arena. Не открывай `github.com/.../blob/.../index.html` как игру — эта страница показывает исходный код.

## Что уже работает

- Полный playable **Урок 1: «Первый контакт»** (`ls`, `cd piscine`, `pwd`).
- Теория → мини-игра → челлендж с автопроверкой и разбором ошибок.
- XP, уровни, стрик, бейдж и анимация награды.
- Сохранение после каждого действия в `localStorage`.
- Экспорт и импорт резервной копии JSON.
- Годовой маршрут: 12 блоков × 8 уроков = 96 миссий.

**Важно:** остальные 95 позиций — план, а не опубликованные playable-уроки. Новые уроки добавляются по одному в массив `LESSONS`; программа не переписывается с нуля.

## Устройство файла

- `ROADMAP` — названия, цели и типы мини-игр всего годового маршрута.
- `ALL` — плоский индекс маршрута, вычисляется автоматически.
- `LESSONS` — содержимое опубликованных уроков.
- `index.html` — единственный файл платформы: HTML, CSS и JS внутри, без CDN, шрифтов и изображений.
